# Widgets

Available Homey Dashboard widgets:

## PostNL My Post

Widget ID: `poststukken`. This widget shows data from its corresponding carrier.

## MyParcel Packages

Widget ID: `myparcel-pakketten`. Select the carrier devices to include.

## Deutsche Post letters

Widget ID: `deutsche-post-poststukken`. This widget shows data from its corresponding carrier.

## PostNL package details

Widget ID: `postnl-pakketdetails`. This widget shows data from its corresponding carrier.

## MyParcel Delivery

Widget ID: `myparcel-bezorging`. Select the carrier devices to include.

Available data depends on the carrier and shipment. Not every field is populated for every parcel.
