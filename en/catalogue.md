# Carrier catalogue

This catalogue lists every carrier from the [reference site](https://ha-parcel-integrations.github.io/carriers/) alongside carriers actually implemented in MyParcel for Homey.

> **Important:** Not all listed carriers work with Homey. Only the drivers shipped in MyParcel v0.3.1 are supported. Account / Tracking / API for other carriers describes the reference catalogue, not Homey functionality.

## Interactive carrier catalogue

The standalone HTML catalogue includes search, country and connection filters, card layouts and a **Details** popup with no GitHub buttons. It is stored in [the repository](https://github.com/LRvdLinden/nl.lrvdlinden.myparcel-docs/blob/main/carriers/index.html). Publish it through GitHub Pages to use it interactively.
