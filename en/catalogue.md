# Carriers

**76 carriers and counting.** This catalogue is based on the [reference list](https://ha-parcel-integrations.github.io/carriers/). Carriers with existing MyParcel for Homey device drivers are labelled **Supported in Homey**; all others are **Coming soon**.

[**Open the interactive carrier catalogue and Details popups →**](https://lrvdlinden.github.io/nl.lrvdlinden.myparcel-docs/carriers/)

Cards include Account / Tracking / API labels, countries, reference versions and Capabilities detail popups. No GitHub buttons. Versions and BETA flags from the reference are not Homey release numbers or maturity labels.
