# MyParcel Docs v1.1.0

Documentation updated to **MyParcel for Homey v0.3.7** (NL and EN).

* **19 carrier pages** generated from the app manifest: image, countries, how to connect, settings, all capabilities and Flow cards (triggers, conditions, actions) with Dutch and English titles, notable tokens and limitations. New pages for **Trunkrs**, **Dynalogic**, **Dragonfly / Intelcom**, **Mondial Relay** and **Amazon** (experimental); Homerr is now **Vinted Go** and InPost UK is now **InPost** (page addresses unchanged).
* **Catalogue:** Trunkrs, Dynalogic, Dragonfly, Intelcom, Mondial Relay, Amazon and BRT (via DPD) are marked **✅ Homey** with a link to their carrier page and image; duplicate cards removed; external version numbers and BETA labels removed; 78 carriers, 21 available in Homey. The interactive page (`carriers/index.html`) has the same data and the capability indicators for all 19 devices.
* **Flow cards, Flow tokens and Device data** regenerated per carrier, including the global PostNL tokens (**Parcel image**, **Latest mail scan**) and the MyParcel delivery tokens.
* **Updated pages:** Welcome (supported carriers, 13 app languages), Install and connect, Widgets (MyParcel Packages/Delivery with *Show all carriers*, PostNL, DHL Parcels Germany, Deutsche Post), Flow examples (incl. Advanced Flow advice), Troubleshooting (repair, single-use sign-in links, rate limits, *Missing token value*) and Changelog (v0.3.2–v0.3.7).
* Table of contents lists all 19 carriers with their current names.

# MyParcel Docs v1.0.0

Initial carrier catalogue release: 76 reference carriers with account/tracking/API badges, native MyParcel for Homey support and Coming soon status, responsive cards, modal carrier details, country filters and no GitHub buttons. GitBook NL/EN landing pages point to the interactive catalogue. GitHub Pages must be enabled to host HTML.
